API reference¶

This page lists the public interface: every name you import from labllm, the test helpers in labllm.testing, and the few public names in labllm.errors and labllm.reviews. labllm.__version__ is the installed version.

It is built from the docstrings in src/labllm/, so this page and the code cannot drift apart. Write the docstring; this page follows.

labllm.client.Gateway ¶

The client of the lab gateway. One per process; safe from many threads.

The gateway's address comes from $LABLLM_GATEWAY, a local address the caller's SSH tunnel serves. A refused connection, or one dropped with no reply, as a tunnel drops it while the gateway restarts, is sent again for connect_retry_s seconds, then raises GatewayUnreachable. A resend never pays twice: the gateway serves one whose call it already answered from the cache, and makes one whose call is in flight wait for it. Its counters then show no cost for that call; the gateway's record and ceiling hold it.

class Gateway:
    """The client of the lab gateway. One per process; safe from many threads.

    The gateway's address comes from `$LABLLM_GATEWAY`, a local address the caller's SSH
    tunnel serves. A refused connection, or one dropped with no reply, as a tunnel drops it
    while the gateway restarts, is sent again for `connect_retry_s` seconds, then raises
    `GatewayUnreachable`. A resend never pays twice: the gateway serves one whose call it
    already answered from the cache, and makes one whose call is in flight wait for it. Its
    counters then show no cost for that call; the gateway's record and ceiling hold it.

    Parameters
    ----------
    repo
        The calling repo's label, recorded with each call.
    person
        Who is calling, recorded with each call. Defaults to the login name.
    transport
        Replaces HTTP to `$LABLLM_GATEWAY`, as `labllm.testing.FakeGateway` does.
    clock
        Every wait goes through it.

    Raises
    ------
    GatewayUnreachable
        No transport is given and `$LABLLM_GATEWAY` is unset or not an `http://host:port`.

    Examples
    --------
    Through a tunnel to the lab gateway, so the doctest run skips each line that needs it:

    >>> from labllm import Gateway, Model
    >>> gw = Gateway(repo="my-repo")  # doctest: +SKIP
    >>> model = Model("deepseek", "deepseek-v4-flash", thinking=False, max_output_tokens=16)
    >>> with gw.meter("first try", ceiling_usd=0.01) as m:  # doctest: +SKIP
    ...     reply = m.chat(model, user="Reply with the single word OK.")
    >>> reply.text  # doctest: +SKIP
    'OK'
    """

    connect_retry_s = 60.0

    def __init__(
        self,
        *,
        repo: str,
        person: str | None = None,
        transport: Transport | None = None,
        clock: Clock | None = None,
    ) -> None:
        if transport is None:
            address = os.environ.get("LABLLM_GATEWAY")
            if not address:
                raise GatewayUnreachable(
                    "set LABLLM_GATEWAY to the local address of your tunnel to the gateway"
                )
            transport = HttpTransport(address)
        self.repo = repo
        self.person = person or getpass.getuser()
        self._transport = transport
        self._clock = clock or SystemClock()

    @property
    def clock(self) -> Clock:
        """The clock every wait goes through, and the one a caller times its calls by."""
        return self._clock

    def meter(self, label: str, *, ceiling_usd: float, off_peak_only: bool = False) -> "Meter":
        """Open a meter: a group of calls under one dollar ceiling.

        Parameters
        ----------
        label
            For people reading the gateway's record. Two meters never share a ceiling,
            whatever their labels.
        ceiling_usd
            Required. The gateway refuses a call whose largest possible cost would cross it.
        off_peak_only
            Send calls only outside the peak hours in the model's price table entry. In peak
            a call waits until they end; a model with no off-peak hours is unaffected.

        Raises
        ------
        ValueError
            `ceiling_usd` is not a finite number of dollars, zero or more.
        """
        if (
            isinstance(ceiling_usd, bool)
            or not isinstance(ceiling_usd, int | float)
            or not math.isfinite(ceiling_usd)
            or ceiling_usd < 0
        ):
            raise ValueError(f"ceiling_usd must be a number of dollars, not {ceiling_usd!r}")
        return Meter(self, label, float(ceiling_usd), off_peak_only)

    def _send(
        self, path: str, body: bytes, wake: threading.Event, paid: Callable[[float, int], None]
    ) -> dict[str, Any] | None:
        """Return the reply, or None if `wake` ended a wait for off-peak hours.

        A peak reply's cost and attempts go to `paid` before the wait.
        """
        deadline = self._clock.now() + self.connect_retry_s
        delay = 0.5
        while True:
            sent = self._clock.now()
            try:
                status, out = self._transport.send(path, body)
            except ConnectionError as e:
                left = deadline - self._clock.now()
                if left <= 0:
                    raise GatewayUnreachable(f"the gateway does not answer: {e}") from e
                self._clock.sleep(min(delay, left))
                delay = min(delay * 2, 8.0)
                continue
            except (OSError, http.client.HTTPException) as e:
                raise GatewayUnreachable(f"the connection to the gateway failed: {e!r}") from e
            try:
                return wire.decode_response(status, out)
            except PeakHours as e:
                paid(e.cost_usd, e.attempts)
                log.info("%s; waiting", e)
                # A gateway clock a little behind this one must not cause a burst of resends.
                self._clock.sleep_until(max(e.until, sent + 1.0), wake)
                if wake.is_set():
                    return None
                deadline = self._clock.now() + self.connect_retry_s
                delay = 0.5

class Meter:
    """Labels, counts and limits a group of calls. Open one with `Gateway.meter`.

    The counters cover every call so far: `spent_usd` paid now, failed calls included;
    `first_cost_usd`, the answers as first paid; `requests` the gateway sent providers, retries
    included; and `cache_hits`, the calls the cache answered, which send none. `id` is the
    meter's identity on the gateway.

    Every call raises a `Stopped` subclass when the caller's loop must stop, and `Rejected`
    when the request is a bug. An off-peak-only call that meets peak hours waits, holding no
    lock, until they end, then is sent again.
    """

    def __init__(self, gateway: Gateway, label: str, ceiling_usd: float, off_peak_only: bool):
        self.id = uuid.uuid4().hex
        self.label = label
        self.ceiling_usd = ceiling_usd
        self.off_peak_only = off_peak_only
        self.spent_usd = 0.0
        self.first_cost_usd = 0.0
        self.requests = 0
        self.cache_hits = 0
        self._gateway = gateway
        self._lock = threading.Lock()
        self._stopped: Stopped | None = None
        self._wake = threading.Event()

    def stop(self, error: Stopped) -> None:
        """Send no further call. Calls already sent finish.

        Each later call, and each one waiting out peak hours, raises `error`'s class with its
        message at once.
        """
        with self._lock:
            self._stopped = self._stopped or error
        self._wake.set()

    def __enter__(self) -> "Meter":
        """Return the meter."""
        return self

    def __exit__(
        self,
        exc_type: type[BaseException] | None,
        exc: BaseException | None,
        tb: TracebackType | None,
    ) -> None:
        """Leave the meter; its counters stay readable."""
        return None

    def chat(
        self,
        model: Model,
        *,
        user: str,
        system: str | None = None,
        schema: dict[str, Any] | None = None,
        tag: str | None = None,
    ) -> ChatReply:
        """Send one chat request and wait for its reply.

        `schema` is a plain JSON Schema dictionary, sent and hashed exactly as written.
        `tag` joins the call's cost to the caller's own row; it never changes the cache key.
        """
        r = self._call(wire.chat_form(model, user=user, system=system, schema=schema), tag)
        return ChatReply(
            r["text"], r["usage"], r["cost_usd"], r["first_cost_usd"], r["cached"], r["attempts"]
        )

    def jev(
        self,
        model: Model,
        *,
        description: str,
        questions: Mapping[str, Any],
        tag: str | None = None,
    ) -> JevReply:
        """Ask Jev closed questions about `description` and wait for its answers.

        `questions` maps each name to a question as Jev's API takes it, such as
        ``{"type": "noul", "instructions": "Is it human?"}``; Jev answers under the same names.
        """
        form = wire.jev_form(model, description=description, questions=questions)
        r = self._call(form, tag)
        return JevReply(
            r["answers"], r["usage"], r["cost_usd"], r["first_cost_usd"], r["cached"], r["attempts"]
        )

    def _call(self, form: dict[str, Any], tag: str | None) -> dict[str, Any]:
        path = wire.PATHS[form["route"]]
        call = wire.Call(
            form=form,
            meter=self.id,
            label=self.label,
            ceiling_usd=self.ceiling_usd,
            off_peak_only=self.off_peak_only,
            person=self._gateway.person,
            repo=self._gateway.repo,
            tag=tag,
        )
        try:
            r = (
                None
                if self._wake.is_set()
                else self._gateway._send(path, call.encode(), self._wake, self._paid)
            )
        except (Stopped, Rejected) as e:
            self._paid(e.cost_usd, e.attempts)
            raise
        if r is None:
            with self._lock:
                stopped = self._stopped
            assert stopped is not None
            raise type(stopped)(str(stopped))
        try:
            cost, first, cached = float(r["cost_usd"]), float(r["first_cost_usd"]), r["cached"]
            # A reply with no count of attempts had one, or none for a hit.
            r["attempts"] = int(r.get("attempts", 0 if cached else 1))
        except (KeyError, TypeError, ValueError) as e:
            raise GatewayUnreachable(f"the gateway's reply lacks {e}") from e
        with self._lock:
            self.spent_usd += cost
            self.first_cost_usd += first
            self.requests += r["attempts"]
            self.cache_hits += bool(cached)
        return r

    def _paid(self, cost_usd: float, attempts: int) -> None:
        """Count what a call that brought no answer paid and sent."""
        with self._lock:
            self.spent_usd += cost_usd
            self.requests += attempts

        for role, r in self.roles.items():

class Unit:
    """One unit as its kind's function sees it: its key, its inputs, and models by role.

    Every call is tagged with the unit's key on the pass's meter. Once the pass has stopped, a
    call raises the stop's error without being sent, and the unit ends unfinished.
    """

    def __init__(
        self,
        key: str,
        inputs: Inputs,
        kind: UnitKind,
        meter: Meter,
        models: Mapping[str, Model],
        stop: _Stop,
        clock: Clock,
    ) -> None:
        self.key = key
        self.inputs = inputs
        self._kind = kind
        self._meter = meter
        self._models = models
        self._stop = stop
        self._clock = clock
        self._stopped: str | None = None
        self._checks: list[CheckResult] = []
        self._lock = threading.Lock()
        self._first: float | None = None
        self._spent = self._first_cost = 0.0
        self._requests = self._cache_hits = 0
        self._usage: dict[str, Any] = {}

    def chat(
        self,
        role: str,
        *,
        user: str,
        system: str | None = None,
        schema: dict[str, Any] | None = None,
    ) -> ChatReply:
        """Send one chat request to the model filling `role`, as `Meter.chat` does."""
        model = self._model(role, "chat")
        return self._send(
            lambda: self._meter.chat(model, user=user, system=system, schema=schema, tag=self.key)
        )

    def jev(self, role: str, *, description: str, questions: Mapping[str, Any]) -> JevReply:
        """Ask the model filling `role` Jev's closed questions, as `Meter.jev` does."""
        model = self._model(role, "jev")
        return self._send(
            lambda: self._meter.jev(
                model, description=description, questions=questions, tag=self.key
            )
        )

    def _send[R: ChatReply | JevReply](self, call: Callable[[], R]) -> R:
        try:
            self._stop.check()
        except Stopped as e:
            self._met(str(e))
            raise
        with self._lock:
            if self._first is None:
                self._first = self._clock.now()
        try:
            reply = call()
        except (Stopped, Rejected) as e:
            with self._lock:
                self._spent += e.cost_usd
                self._requests += e.attempts
            if isinstance(e, Stopped):
                self._stop.halt(e)
                # A call the stop ended unsent says so as a call never sent does.
                self._met(str(e) if str(e) == self._stop.message else f"{e.reason}: {e}")
            raise
        with self._lock:
            self._spent += reply.cost_usd
            self._first_cost += reply.first_cost_usd
            self._cache_hits += bool(reply.cached)
            self._requests += reply.attempts
            if isinstance(reply.usage, Mapping):
                _add_usage(self._usage, reply.usage)
        return reply

    def _met(self, reason: str) -> None:
        with self._lock:
            self._stopped = self._stopped or reason

    def _cost(self) -> UnitCost:
        """Return the unit's cost so far, timed to now."""
        with self._lock:
            seconds = None if self._first is None else self._clock.now() - self._first
            return UnitCost(
                self._spent,
                self._first_cost,
                self._requests,
                self._cache_hits,
                copy.deepcopy(self._usage),
                seconds,
            )

    def each[T, R](self, fn: Callable[[T], R], items: Iterable[T], *, at_once: int = 8) -> list[R]:
        """Call `fn` on every item, `at_once` at a time, and return the results in item order.

        For many requests at once within the unit. Once `fn` raises, no further item starts;
        the running ones finish, then the first error is raised. `u.settle` and `u.refuse`
        inside `fn` end the unit as they would outside it.

        Raises
        ------
        ValueError
            `at_once` is below one.
        """
        if at_once < 1:
            raise ValueError(f"at_once must be one or more, not {at_once}")
        items = list(items)
        results: list[Any] = [None] * len(items)

        def one(i: int) -> None:
            results[i] = fn(items[i])

        _at_once(one, iter(range(len(items))), min(at_once, len(items)), halted=lambda: False)
        return results

    def check(self, name: str, message: str | None) -> None:
        """Record a check: `message` None passes, a string fails and makes the unit unsettled."""
        with self._lock:
            self._checks.append(CheckResult(name, message))

    def refuse(self, name: str, message: str) -> NoReturn:
        """End the unit refused, keeping no answer. The message is recorded as a failed check."""
        raise _Refuse(name, message)

    def settle(self, answer: Any) -> NoReturn:
        """End the unit with `answer`, decided by code alone.

        The answer must fit the answer schema; the answer checks do not run on it. The unit
        ends settled unless a check recorded with `check` failed, then unsettled.
        """
        raise _Settle(answer)

    def _model(self, role: str, route: str) -> Model:
        r = self._kind.roles.get(role)
        if r is None or r.route != route:
            raise ValueError(f"kind {self._kind.name!r} has no {route} role {role!r}")
        return self._models[role]

    it holds the task; a holder counts as gone once its process ends, or once that file goes
    two minutes untouched. Close the task, or end the process, to let another open it.

    Parameters
    ----------
    folder
        Holds the state file, `state.sqlite`. Made if missing.
    gateway
        Every pass's calls go through it.
    reviews
        The folder of the kinds' review files.

    Raises
    ------
    TaskInUse
        Another process holds the task. The message names it.
    UnknownLayout
        The state file is not one this version of liulab-llms can read.
    """

    def __init__(
        self, folder: str | os.PathLike[str], *, gateway: Gateway, reviews: str | os.PathLike[str]
    ) -> None:
        self.folder = Path(folder)
        self.reviews = Path(reviews)
        self.folder.mkdir(parents=True, exist_ok=True)
        self.path = self.folder / "state.sqlite"
        self._gateway = gateway
        self._reviews = Reviews(self.reviews, clock=gateway.clock)
        self._state = StateFile(self.path)

    def close(self) -> None:
        """Close the state file."""
        self._state.close()

    def __enter__(self) -> "Task":
        """Return the task."""
        return self

    def __exit__(
        self,
        exc_type: type[BaseException] | None,
        exc: BaseException | None,
        tb: TracebackType | None,
    ) -> None:
        """Close the task."""
        self.close()

    def run_pass(
        self,
        kind: UnitKind,
        keys: Iterable[str],
        *,
        models: Mapping[str, Model],
        ceiling_usd: float,
        label: str,
        off_peak_only: bool = False,
        units_at_once: int = 32,
    ) -> PassResult:
        """Run `kind` over `keys`, starting them in the order given, under one new meter.

        `units_at_once` units run at once, each on its own thread, so the kind's function must
        be safe to run on many threads. Each unit's outcome and cost are recorded as it ends.

        A `Stopped` error stops the pass. Calls already sent finish and are paid; no new call
        is sent and no new unit starts. The unit that met the error, every unit that then
        tries a call, and every unit not started end unfinished, with the reason recorded.
        A unit that needs no further call keeps its ending.

        With `off_peak_only`, a call that meets peak hours waits until they end, then goes
        out; a stop ends that wait at once.

        Raises
        ------
        ValueError
            `models` does not fill exactly the kind's roles, `keys` repeats a key, or
            `units_at_once` is below one.
        TypeError
            A key is not a string.
        """
        if units_at_once < 1:
            raise ValueError(f"units_at_once must be one or more, not {units_at_once}")
        keys = list(keys)
        if not all(isinstance(key, str) for key in keys):
            raise TypeError("every key must be a string")
        if set(models) != set(kind.roles):
            raise ValueError(f"models fill roles {sorted(models)}; kind has {sorted(kind.roles)}")
        if len(set(keys)) != len(keys):
            raise ValueError("keys repeat a key")
        meter = self._gateway.meter(label, ceiling_usd=ceiling_usd, off_peak_only=off_peak_only)
        pass_id = self._state.start_pass(
            PassStart(
                meter=meter.id,
                kind=kind.name,
                kind_version=kind.version,
                label=label,
                models=dict(models),
                ceiling_usd=meter.ceiling_usd,
                off_peak_only=off_peak_only,
                repo_version=_repo_version(kind.run),
                labllm_version=version("liulab-llms"),
            )
        )
        counts: dict[str, int] = dict.fromkeys((*PASS_ENDINGS, *NOT_ENDINGS), 0)
        lock = threading.Lock()
        stop = _Stop(meter)

        def work(key: str) -> None:
            ended = self._run_unit(kind, key, meter, models, stop)
            self._state.record(
                kind.name,
                key,
                pass_id,
                ending=ended.ending,
                inputs_tag=ended.inputs_tag,
                answer_json=ended.answer_json,
                reason=ended.reason,
                checks=ended.checks,
                cost=ended.cost,
            )
            with lock:
                counts[ended.ending] += 1

        rest = iter(keys)
        with meter:
            _at_once(work, rest, units_at_once, halted=lambda: stop.error is not None)
        stopped = stop.reason
        unstarted = list(rest)
        if unstarted:
            self._state.record_unstarted(
                kind.name, unstarted, pass_id, reason=f"the pass stopped: {stopped}"
            )
            counts["unfinished"] += len(unstarted)
        self._state.end_pass(
            pass_id,
            stopped=stopped,
            spent_usd=meter.spent_usd,
            first_cost_usd=meter.first_cost_usd,
            requests=meter.requests,
            cache_hits=meter.cache_hits,
        )
        return PassResult(
            pass_id=pass_id,
            meter=meter.id,
            counts=counts,
            stopped=stopped,
            spent_usd=meter.spent_usd,
            first_cost_usd=meter.first_cost_usd,
            requests=meter.requests,
            cache_hits=meter.cache_hits,
        )

    def _run_unit(
        self, kind: UnitKind, key: str, meter: Meter, models: Mapping[str, Model], stop: _Stop
    ) -> _Ended:
        """Run one unit to its outcome.

        A unit that met the pass's stop ends unfinished, whatever its code did next.
        """
        ended = _Ended("unfinished")
        unit: Unit | None = None
        try:
            inputs = kind.load(key)
            if not isinstance(inputs, Inputs) or not isinstance(inputs.tag, str):
                raise TypeError(f"load returned {inputs!r}, not Inputs with a str tag")
            ended.inputs_tag = inputs.tag
            unit = Unit(key, inputs, kind, meter, models, stop, self._gateway.clock)
            ended.checks = unit._checks
            try:
                answer = kind.run(unit)
            except _Settle as s:
                ended.answer_json, _ = kind.fit(s.answer)
                failed = any(not c.passed for c in ended.checks)
                ended.ending = "unsettled" if failed else "settled"
            except _Refuse as r:
                unit.check(r.name, r.message)
                ended.ending, ended.reason = "refused", r.message
            else:
                ended.answer_json, results = kind.fit(answer, inputs)
                for result in results:
                    unit.check(result.name, result.message)
                failed = any(not c.passed for c in ended.checks)
                ended.ending = "unsettled" if failed else "settled"
        except Held as h:
            ended = _Ended("held", ended.inputs_tag, reason=str(h), checks=ended.checks)
        except Stopped as e:
            stop.halt(e)
            reason = f"{e.reason}: {e}"
            ended = _Ended("unfinished", ended.inputs_tag, reason=reason, checks=ended.checks)
        except Exception as e:
            reason = "".join(traceback.format_exception(e, limit=-3))
            ended = _Ended("unfinished", ended.inputs_tag, reason=reason, checks=ended.checks)
        if unit is not None:
            if unit._stopped is not None:
                ended = _Ended("unfinished", ended.inputs_tag, reason=unit._stopped)
                ended.checks = unit._checks
            ended.cost = unit._cost()
        return ended

    def current(self, kind: UnitKind, key: str) -> Outcome | None:
        """Return the unit's current answer: its outcome in the latest pass that reached an ending.

        A person's review outranks it while that outcome's inputs tag is the one the review
        was made for; of such reviews, the newest wins. None if no pass has reached an ending
        for the unit. Unfinished and held change nothing.
        """
        outcome = self._state.current(kind.name, key)
        if outcome is None:
            return None
        review = holding(self._reviews.by_unit(kind).get(key, ()), outcome.stamp.inputs_tag)
        if review is None:
            return outcome
        return dataclasses.replace(
            outcome,
            ending=review.ending,
            answer=review.answer,
            checks=review.checks,
            reason=review.note if review.drop else None,
            review=review,
        )

    def save_review(
        self,
        kind: UnitKind,
        key: str,
        *,
        who: str,
        answer: Any = NO_ANSWER,
        drop: bool = False,
        note: str = "",
        overrides: Mapping[str, str] | None = None,
        accepted_pass: int | None = None,
    ) -> Review:
        """Check, stamp and save one person's review of the unit's current answer.

        As `Reviews.save` does, for the inputs tag of the unit's latest pass that reached an
        ending.

        Raises
        ------
        ValueError
            No pass has reached an ending for the unit, or as `Reviews.save` raises.
        """
        outcome = self._state.current(kind.name, key)
        if outcome is None or outcome.stamp.inputs_tag is None:
            raise ValueError(f"no pass has reached an ending for {key!r}: there is no answer")
        return self._reviews.save(
            kind,
            key,
            who=who,
            inputs_tag=outcome.stamp.inputs_tag,
            answer=answer,
            drop=drop,
            note=note,
            overrides=overrides,
            accepted_pass=accepted_pass,
        )

    def outcomes(self, kind: UnitKind, key: str) -> list[Outcome]:
        """Return the unit's outcome in every pass that ran it, oldest first."""
        return self._state.outcomes(kind.name, key)

    def keys(self, kind: UnitKind, *, endings: Iterable[str]) -> list[str]:
        """Return the keys whose current ending is one of `endings`, in key order.

        Raises
        ------
        ValueError
            One of `endings` is not an ending.
        """
        wanted = set(endings)
        if unknown := wanted - set(ENDINGS):
            raise ValueError(f"not endings: {sorted(unknown)}; endings are {list(ENDINGS)}")
        reviews = self._reviews.by_unit(kind)
        keys = []
        for key, ending, tag in self._state.latest(kind.name):
            review = holding(reviews.get(key, ()), tag)
            if (ending if review is None else review.ending) in wanted:
                keys.append(key)
        return keys

    def review_queue(self, kind: UnitKind) -> list[QueueEntry]:
        """Return every unit whose current answer is unsettled or refused, in key order."""
        reviews = self._reviews.by_unit(kind)
        queue = []
        for key in self.keys(kind, endings=("unsettled", "refused")):
            outcomes = self._state.outcomes(kind.name, key)
            current = next(o for o in reversed(outcomes) if o.ending in ENDINGS)
            queue.append(
                QueueEntry(
                    kind=kind.name,
                    key=key,
                    ending=current.ending,
                    inputs_tag=current.stamp.inputs_tag or "",
                    outcomes=tuple(outcomes),
                    failed=tuple(c for c in current.checks if not c.passed),
                    spent_usd=sum(o.cost.spent_usd for o in outcomes if o.cost is not None),
                    reviews=reviews.get(key, ()),
                )
            )
        return queue

class Reviews:
    """The reviews folder: one JSON Lines file per kind, `<kind name>.jsonl`, one review a line.

    Needs no task and no state file, so it takes reviews while a pass holds the task.

    Parameters
    ----------
    folder
        The reviews folder. Made on the first save.
    clock
        Gives each review's time.
    """

    def __init__(self, folder: str | os.PathLike[str], *, clock: Clock | None = None) -> None:
        self.folder = Path(folder)
        self._clock = clock or SystemClock()
        self._lock = threading.Lock()
        self._read: dict[Path, tuple[tuple[int, int, int], _Read]] = {}

    def path(self, kind: "UnitKind") -> Path:
        """Return the kind's review file."""
        return self.folder / f"{kind.name}.jsonl"

    def save(
        self,
        kind: "UnitKind",
        key: str,
        *,
        who: str,
        inputs_tag: str,
        answer: Any = NO_ANSWER,
        drop: bool = False,
        note: str = "",
        overrides: Mapping[str, str] | None = None,
        accepted_pass: int | None = None,
    ) -> Review:
        """Check one person's review of one unit, stamp it, and add it to the kind's file.

        Give `answer` or `drop=True`, not both. The answer must fit the kind's answer schema,
        and the kind's answer checks run on it. A failed check stops the save unless
        `overrides` gives a reason for it, by the check's name; the review keeps every check's
        result.

        `inputs_tag` is the inputs tag of the answer reviewed, as its `QueueEntry` gives it. The
        checks run on the inputs `kind.load(key)` returns now, which must have that tag.

        Raises
        ------
        ChecksFailed
            An answer check failed and is not overridden. Nothing is saved.
        ValueError
            The unit's inputs changed since the answer reviewed, the answer does not fit the
            schema, both or neither of `answer` and `drop` are given, a drop has no note, or an
            override names no answer check or gives no reason.
        Held
            The unit's inputs are not there.
        """
        if drop != (answer is NO_ANSWER):
            raise ValueError("give an answer or drop=True, not both or neither")
        if drop and not note:
            raise ValueError("a drop needs a note giving its reason")
        overrides = dict(overrides or {})
        names = {c.__name__ for c in kind.answer_checks}
        for name, reason in overrides.items():
            if name not in names:
                raise ValueError(f"{name!r} is not one of the kind's answer checks {sorted(names)}")
            if not reason:
                raise ValueError(f"the override of {name!r} needs a reason")
        inputs = kind.load(key)
        if inputs.tag != inputs_tag:
            raise ValueError(
                f"the inputs of {key!r} changed since the answer reviewed, from {inputs_tag!r} "
                f"to {inputs.tag!r}: rerun a pass, then review its answer"
            )
        checks: tuple[CheckResult, ...] = ()
        if not drop:
            text, checks = kind.fit(answer, inputs)
            answer = json.loads(text)
            if failed := tuple(c for c in checks if not c.passed and c.name not in overrides):
                raise ChecksFailed(failed)
        review = Review(
            kind=kind.name,
            key=key,
            who=who,
            when=datetime.fromtimestamp(self._clock.now(), UTC),
            kind_version=kind.version,
            inputs_tag=inputs_tag,
            answer=None if drop else answer,
            drop=drop,
            note=note,
            overrides=overrides,
            accepted_pass=accepted_pass,
            checks=checks,
        )
        self.folder.mkdir(parents=True, exist_ok=True)
        _append(self.path(kind), _line(review))
        return review

    def read(self, kind: "UnitKind") -> list[Review]:
        """Return the kind's reviews in file order.

        A line cut short at the end of the file, as a crash while saving leaves it, is
        skipped. Any other line that is not a review is skipped with a warning.
        """
        return list(self._load(kind).reviews)

    def by_unit(self, kind: "UnitKind") -> dict[str, tuple[Review, ...]]:
        """Return each unit's reviews, oldest first: by time, then by file order."""
        return self._load(kind).by_key

    def _load(self, kind: "UnitKind") -> "_Read":
        """Read the kind's file again only if it has changed since the last read."""
        path = self.path(kind)
        try:
            st = path.stat()
        except FileNotFoundError:
            return _Read((), {})
        seen = (st.st_ino, st.st_size, st.st_mtime_ns)
        with self._lock:
            cached = self._read.get(path)
        if cached is not None and cached[0] == seen:
            return cached[1]
        reviews = tuple(_parse(path, path.read_bytes()))
        by_key: dict[str, list[Review]] = {}
        for review in sorted(reviews, key=lambda r: r.when):
            by_key.setdefault(review.key, []).append(review)
        read = _Read(reviews, {key: tuple(rs) for key, rs in by_key.items()})
        with self._lock:
            self._read[path] = (seen, read)
        return read

class FakeClock:
    """A clock the test owns: `sleep` returns at once and moves `now` forward."""

    def __init__(self, start: float = 0.0) -> None:
        self._now = start
        self._lock = threading.Lock()
        self._parked = threading.Condition(self._lock)
        self._waiting = 0

    def now(self) -> float:
        """Seconds since the Unix epoch, as far as this clock has moved."""
        with self._lock:
            return self._now

    def sleep(self, seconds: float) -> None:
        """Move `now` forward by `seconds` and return."""
        with self._lock:
            self._now += seconds

    def sleep_until(self, t: float, wake: threading.Event | None = None) -> None:
        """Move `now` forward to `t`, unless it is already later or `wake` is set, and return.

        Threads waiting for one moment wake together, as they would in real time.
        """
        if wake is not None and wake.is_set():
            return
        with self._lock:
            self._now = max(self._now, t)

    def wait(self, condition: threading.Condition, until: float | None = None) -> None:
        """Move `now` forward to `until` and return; with no `until`, wait to be notified.

        `until_waiting` sees each thread waiting with no `until`.
        """
        if until is not None:
            self.sleep_until(until)
            return
        with self._parked:
            self._waiting += 1
            self._parked.notify_all()
        try:
            condition.wait()
        finally:
            with self._parked:
                self._waiting -= 1
                self._parked.notify_all()

    def until_waiting(self, threads: int, timeout: float = 10.0) -> None:
        """Block until `threads` threads wait in `wait` with no `until`.

        Raises
        ------
        TimeoutError
            They did not, within `timeout` real seconds.
        """
        with self._parked:
            if not self._parked.wait_for(lambda: self._waiting >= threads, timeout):
                raise TimeoutError(f"{self._waiting} threads wait, not {threads}")

class FakeGateway:
    """Stands in for the gateway, keeping its rules, with `provider` playing the provider.

    One cache by request form; a hit costs nothing and never counts against a ceiling, and a
    call identical to one in flight waits for it. Each meter's ceiling, with every call in
    flight holding back its largest possible cost, by the real gateway's rule in
    `labllm.ceiling`. A model missing from `prices` is `Rejected`. Every attempt and hit goes
    in `record`. An off-peak-only call that is not a hit gets the peak reply in its price's
    peak hours, and from `peak_margin_s` before they start.

    The provider's tokens are counted as characters: input is the messages' text, or Jev's
    description and its questions as JSON; output is the reply text, or Jev's answers as JSON.

    Examples
    --------
    >>> from labllm import Model
    >>> fake = FakeGateway(lambda form: "hi", prices={"m": Price(0.0, 0.001)})
    >>> with fake.client(repo="docs").meter("example", ceiling_usd=5.0) as m:
    ...     m.chat(Model("openai", "m"), user="hello").text
    'hi'
    """

    def __init__(
        self,
        provider: Provider,
        *,
        prices: Mapping[str, Price],
        clock: FakeClock | None = None,
        peak_margin_s: float = peak.MARGIN_S,
    ) -> None:
        self.clock = clock or FakeClock()
        self._peak_margin_s = peak_margin_s
        self._provider = provider
        self._prices = dict(prices)
        self._lock = threading.Lock()
        self._cache: dict[str, tuple[Any, dict[str, Any], float]] = {}
        self._ceilings = Ceilings()
        self._record: list[Exchange] = []
        self._refusals: float = 0
        self._flights = Flights(self.clock)

    @property
    def record(self) -> list[Exchange]:
        """Every exchange so far, oldest first."""
        with self._lock:
            return list(self._record)

    def client(self, *, repo: str = "tests", person: str | None = None) -> Gateway:
        """Return a `Gateway` client of this fake, on its clock."""
        return Gateway(repo=repo, person=person, transport=self, clock=self.clock)

    def refuse_connections(self, times: int | None = None) -> None:
        """Refuse the next `times` connections, or every one from now on if `times` is None."""
        with self._lock:
            self._refusals = float("inf") if times is None else times

    def send(self, path: str, body: bytes) -> tuple[int, bytes]:
        """Answer one request body, as the gateway answers an HTTP post."""
        with self._lock:
            if self._refusals > 0:
                self._refusals -= 1
                raise ConnectionRefusedError("the fake gateway refused the connection")
        try:
            call = wire.Call.decode(body)
            if path != wire.PATHS[call.form["route"]]:
                raise Rejected(f"{path} does not take a {call.form['route']} call")
            return wire.encode_reply(self._answer(call))
        except (Stopped, Rejected, PeakHours) as e:
            return wire.encode_error(e)

    def _answer(self, call: wire.Call) -> dict[str, Any]:
        key = wire.cache_key(call.form)
        hit = self._hit(call, key)
        if hit is not None:
            return hit
        with self._lock:
            price = self._prices.get(call.form["model"])
        if price is None:
            raise Rejected(f"no price for model {call.form['model']!r}")
        with self._flights.claim(key):
            hit = self._hit(call, key)
            if hit is not None:
                return hit
            return self._attempts(call, key, price)

    def _hit(self, call: wire.Call, key: str) -> dict[str, Any] | None:
        with self._lock:
            hit = self._cache.get(key)
            if hit is None:
                return None
            self._log(call, key, cached=True)
        out, usage, first_cost = hit
        return wire.reply(
            call.form["route"],
            out,
            usage,
            cost_usd=0.0,
            first_cost_usd=first_cost,
            cached=True,
            attempts=0,
        )

    def _attempts(self, call: wire.Call, key: str, price: Price) -> dict[str, Any]:
        form, meter = call.form, call.meter
        input_tokens = _input_tokens(form)
        reserve = largest_cost(price, form)
        retries = Retries(self.clock)
        paid = 0.0
        try:
            while True:
                if call.off_peak_only:
                    peak.check(price.off_peak, self.clock.now(), self._peak_margin_s)
                self._ceilings.hold(call, reserve)
                retries.attempts += 1
                try:
                    out = self._provider(form)
                except Exception as e:
                    failure = unreadable(e, form["provider"])
                    self._ceilings.settle(meter, reserve, 0.0)
                    with self._lock:
                        self._log(call, key, form=form, error=failure.reason)
                    if not isinstance(failure, ProviderUnavailable):
                        raise
                    self.clock.sleep_until(retries.again(failure))
                    continue
                except BaseException:
                    self._ceilings.settle(meter, reserve, 0.0)
                    raise
                chat = form["route"] == "chat"
                output_tokens = len(out) if chat else len(json.dumps(out))
                usage = {"input_tokens": input_tokens, "output_tokens": output_tokens}
                cost = (
                    input_tokens * price.input_usd_per_token
                    + output_tokens * price.output_usd_per_token
                )
                empty = None if out else ProviderUnavailable("the provider sent an empty reply")
                self._ceilings.settle(meter, reserve, cost)
                with self._lock:
                    if empty is not None:
                        self._log(call, key, form=form, error=empty.reason, cost_usd=cost)
                    else:
                        self._cache.setdefault(key, (out, usage, cost))
                        reply = {wire.output_field(form["route"]): out}
                        self._log(call, key, form=form, reply=reply, cost_usd=cost)
                if empty is not None:
                    paid += cost
                    self.clock.sleep_until(retries.again(empty))
                    continue
                return wire.reply(
                    form["route"],
                    out,
                    usage,
                    cost_usd=paid + cost,
                    first_cost_usd=cost,
                    cached=False,
                    attempts=retries.attempts,
                )
        except (Stopped, Rejected, PeakHours) as e:
            e.cost_usd, e.attempts = paid, retries.attempts
            raise

    def _log(
        self,
        call: wire.Call,
        key: str,
        *,
        cached: bool = False,
        form: dict[str, Any] | None = None,
        reply: dict[str, Any] | None = None,
        error: str | None = None,
        cost_usd: float = 0.0,
    ) -> None:
        self._record.append(
            Exchange(
                key=key,
                cached=cached,
                meter=call.meter,
                label=call.label,
                ceiling_usd=call.ceiling_usd,
                off_peak_only=call.off_peak_only,
                person=call.person,
                repo=call.repo,
                tag=call.tag,
                form=form,
                reply=reply,
                error=error,
                cost_usd=cost_usd,
            )
        )

class OffPeak:
    """A model's off-peak hours, as LiteLLM's price table writes them under `off_peak_pricing`.

    Read the way LiteLLM's cost function reads them: `hours_utc` windows that apply every day,
    and `windows` entries whose hours apply on their ISO `weekdays`, read on the calendar of
    `weekday_timezone` (UTC by default). A window `"HH:MM-HH:MM"` includes its start, excludes
    its end, may wrap past midnight, and covers the whole day when its ends are equal.
    Malformed windows are ignored. Peak hours are every other hour.
    """

    def __init__(self, rules: Sequence[_Rule], weekday_tz: tzinfo) -> None:
        self._rules = tuple(rules)
        self._tz = weekday_tz
        self._edges = sorted({m for _, spans in self._rules for span in spans for m in span})

    @classmethod
    def read(cls, block: Any) -> "OffPeak | None":
        """Read a table entry's `off_peak_pricing` block; None if it gives no off-peak hours.

        Examples
        --------
        >>> weekends = OffPeak.read({"windows": [{"hours_utc": "00:00-00:00", "weekdays": [6, 7]}]})
        >>> weekends.is_off_peak(datetime(2026, 11, 7, 12, tzinfo=UTC).timestamp())  # a Saturday
        True
        """
        if not isinstance(block, Mapping):
            return None
        rules: list[_Rule] = []
        if spans := _spans(block.get("hours_utc")):
            rules.append((None, spans))
        windows = block.get("windows")
        if isinstance(windows, Sequence) and not isinstance(windows, str):
            for rule in windows:
                if isinstance(rule, Mapping) and (spans := _spans(rule.get("hours_utc"))):
                    rules.append((_days(rule.get("weekdays")), spans))
        if not rules:
            return None
        return cls(rules, _calendar(block.get("weekday_timezone")))

    def is_off_peak(self, t: float) -> bool:
        """Whether `t`, in seconds since the Unix epoch, falls in an off-peak hour."""
        moment = datetime.fromtimestamp(t, UTC)
        second = t - datetime.combine(moment.date(), time(), UTC).timestamp()
        weekday = moment.astimezone(self._tz).isoweekday()
        for days, spans in self._rules:
            if days is not None and weekday not in days:
                continue
            for start, end in spans:
                start_s, end_s = start * 60, end * 60
                inside = start_s <= second < end_s if start < end else not end_s <= second < start_s
                if inside:
                    return True
        return False

    def peak_ends(self, t: float, margin_s: float) -> float | None:
        """When an off-peak-only call that arrives at `t` may go out; None if at once.

        A call may go out when no peak hour starts within `margin_s` of it, so the answer is
        the end of the peak it would meet, or a later end when the off-peak hours between
        are shorter than the margin.
        """
        send = t
        for _ in range(64):
            start = send if not self.is_off_peak(send) else self._change_after(send)
            if start is None or start > send + margin_s:
                return None if send == t else send
            end = self._change_after(start)
            if end is None:  # never off-peak again: these hours cannot be waited out
                return None
            send = end
        return send

    def _change_after(self, t: float) -> float | None:
        """Return the first moment after `t` across a peak boundary, within a week."""
        state = self.is_off_peak(t)
        for edge in self._boundaries(t):
            if edge > t and self.is_off_peak(edge) != state:
                return edge
        return None

    def _boundaries(self, t: float) -> Iterator[float]:
        day = math.floor(t / _DAY) * _DAY
        local = datetime.fromtimestamp(t, self._tz).date()
        edges: set[float] = set()
        for n in range(-1, 9):
            edges.update(day + n * _DAY + m * 60 for m in (0, *self._edges))
            edges.add(_midnight(local + timedelta(days=n), self._tz))
        yield from sorted(edges)

def peak_ends(self, t: float, margin_s: float) -> float | None:
    """When an off-peak-only call that arrives at `t` may go out; None if at once.

    A call may go out when no peak hour starts within `margin_s` of it, so the answer is
    the end of the peak it would meet, or a later end when the off-peak hours between
    are shorter than the margin.
    """
    send = t
    for _ in range(64):
        start = send if not self.is_off_peak(send) else self._change_after(send)
        if start is None or start > send + margin_s:
            return None if send == t else send
        end = self._change_after(start)
        if end is None:  # never off-peak again: these hours cannot be waited out
            return None
        send = end
    return send

The examples are tests¶

pixi run check runs the Examples blocks in src/labllm/, so an example that no longer matches its code fails the tests.

Write one where it makes the object easier to use, and leave it out where it would not. An example nobody keeps up to date is worse than none.

Keep an example cheap, offline and deterministic. It has to give the same answer on any machine, with no network. A line that cannot do that needs # doctest: +SKIP at the end of that line. A call to the lab gateway is such a line, as in the Gateway example above.

Two things about that marker are easy to get backwards:

  • It covers only the line it sits on. It does not carry to the line below. In a block that mixes lines that run with lines that cannot, each line that cannot run needs its own.
  • A trailing comment written as plain prose looks just like a marker and is not one. Only the # doctest: form is read as one.
